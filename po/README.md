# Translations

Gettext catalogs for the user interface, one folder for each language: `reverblabr.po` (the window, its notifications and the background engine), `reverblabr-ctl.po` (the command-line tool), `plasma_applet_io.github.reverblabr.sessions.po` (the panel widget) and `reverblabr-data.po` (what the desktop shows of Reverblabr: its desktop entry, notification events, KRunner entry and AppStream data). The templates are generated from the sources and not kept here. How to update and check the catalogs, and how to add a language: [Internationalization](../docs/i18n.md#the-translations).
